# Delivery Summary — microduck-cli: env, teach, operate, rules

plan: `microduck-cli-env-teach-operate-rules` · run: `complete` · date: `2026-09-03`
baseline: `devague summary skeleton`

## Intent

Turn the mesh-agent scaffold into the MicroDuck CLI the spec announced: bring up
a duck (the MuJoCo twin driven by the real `robotd` today, a physical duck at the
same socket later), operate it in `robotctl`'s words, drive the `microduck_rl`
training lane without importing it, and run an off-board rules engine whose
data-only rules and agent-injected intents go through one admission path. The
plan executed was the 23-task, six-wave plan exported on 2026-09-03
(`docs/plans/2026-09-03-microduck-cli-env-teach-operate-rules.md`), fanned out by
`/assign-to-workforce` with one worktree per task and a TDD gate on every merge,
on the integration branch `duck/integration` (`cea7f23..e50da18`, 62 commits,
103 files, 32 658 insertions).

## Mid-work Decisions

- `d1` — The pinned simulator daemon speaks API_VERSION 16 and has no policy
  channel (`robot.policies`, `robot.loadPolicy`, `policy.*`, `account.*` landed
  on `main` after the sim branch forked); policy verbs are built against `main`'s
  method names and exit 2 with a `needs API >= 18` remediation on the pinned
  build, skills come from `robot.subscribe`, and the fake serves both shapes —
  discovered by probing the real built daemon before wave 1 merged (approved).
- The real daemon was probed before wave 1 and its exact wire shapes fed to the
  fake-daemon and sense tasks mid-flight; this is why the fake's validation
  messages are serde-verbatim and why the sense fields are no longer provisional.
- One integration branch (`duck/integration`) and one PR at the end, instead of
  one PR per wave, because the PR was ordered to come only after
  `/validate-delivery` and `/summarize-delivery`.
- `achieved_hz` was re-defined as wall-clock cadence and the work-only figure kept
  as `capacity_hz`, after the first live run printed "5935 Hz achieved" for a
  paced 50 Hz loop (delta `b2`).
- The intent yaw axis was renamed `wz` → `vyaw`, the wire's and upstream docs'
  name (delta `b3`).
- Discrete channels are edge-triggered in the sink so a held skill claim sends
  `robot.do` once, not fifty times a second (delta `b4`).
- The train lane resolves the RL clone the way `env doctor` does, after the
  first smoke attempt leaked an "unexpected FileNotFoundError" (delta `b5`).
- On-box verification became an opt-in live pytest suite rather than a manual
  walkthrough (delta `b8`, superseding `b6`).
- Walking in the MuJoCo body was investigated and **not achieved** at this pin:
  the walk network engages but outputs a static pose; upstream's own `drive`
  shape behaves the same, and upstream's launcher does not start at this pin pair
  (delta `b9`, proposed; plan risk `r8`).
